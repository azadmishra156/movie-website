# 🎬 Movie Browser Website

A sleek and responsive web application to browse and explore movies online. Built using HTML, CSS, and JavaScript, this project features dynamic movie fetching, search functionality, category filtering, and a visually appealing user interface.

## ✨ Features

-   ✅ Browse trending, popular, and top-rated movies
-   ✅ Search for movies by title
-   ✅ Filter movies by genre
-   ✅ Responsive and mobile-friendly layout
-   ✅ Hover effects and interactive movie cards
-   ✅ Movie details popup with rating, release date, and overview
-   ✅ Smooth animations and transitions

## 🛠️ How to Set Up and Run the Project

### Prerequisites

-   A modern web browser (Chrome, Firefox, Edge, etc.)
-   A code editor (e.g., VS Code, Sublime Text)
-   Internet connection (for fetching movie data via API)

### 🚀 Run Locally

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/azadmishra156/movie-website.git](https://github.com/azadmishra156/movie-website.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd movie-website
    ```

3.  **Open the Project:**
    Open the `index.html` file in your preferred web browser.

    > **Optional (Recommended):** To avoid potential issues with API calls, it's best to serve the files using a local server. A great tool for this is the **[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)** extension for VS Code.

## 💻 Technologies Used

-   **HTML5:** Structure of the website
-   **CSS3:** Styling, animations, and responsive design
-   **JavaScript (ES6+):** Dynamic content and interactivity
-   **Movie API:** For fetching movie data
